Add proxy

Ex: shop.example.com → VPS-1(10.10.10.1) → WireGuard → VPS-2 Webserver(http://10.10.10.25:80)

  • Domain: the public hostname that visitors use to access your website or application.
  • Upstream: the HTTP address of the web server that VPS-1 forwards requests to, such as http://10.10.10.25:80 or http://10.10.10.212:3000.
  • The website or application must already be running on the upstream device, and VPS-1 must be able to reach its address.
  • After adding the proxy, use the Reverse proxies section to issue an SSL certificate for the domain.
